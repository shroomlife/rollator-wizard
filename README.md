# Rollator-Wizard für Oma

Ein kleiner Single-Page-Wizard, mit dem meine Oma (85) aus einer kuratierten Auswahl an leichten, faltbaren Rollatoren ihre Lieblinge wählen kann. Am Ende generiert die Seite einen kopierbaren Text, den sie mir per WhatsApp schicken kann.

**Live:** https://shroomlife.github.io/rollator-wizard/

## Kontext

- Oma hatte 2025 den linken Arm gebrochen, 2026 die rechte Schulter — braucht etwas Leichtes
- Familie fährt Ende Juni 2026 mit dem BYD Seal U DM-i Touring an die Ostsee — Rollator muss klein faltbar sein
- Budget: unter 500 EUR
- Lieferbar nach Deutschland

## Stack

- Single HTML-Datei (vanilla CSS + Vanilla JS)
- Robin-Design-Style (Mint / Peach / Coral / warmes Cream, Light Mode, Sans-Serif, Glassmorphism)
- og:image via Recraft AI generiert
- Deploy: GitHub Pages

## Use

`index.html` direkt im Browser öffnen oder via GitHub Pages aufrufen.
